# Build journal

Decisions, dead ends, and before/after examples, one dated line each. This becomes the case study.

- 2026-11-03: Set up the repo for phase 1: folder structure from CLAUDE.md, package.json with TypeScript, the Anthropic SDK and Playwright, and .env.example. No generation code yet.
- 2026-11-03: Defined demo brand one, Half Acre Club (warm and handmade): a fictional monthly growing kit for renters. Scott picked the business, the audience, and the voice reference line ("Pea shoots. Ten days. One windowsill. You've got this.") over a gushing and a wry alternative. Drafted positioning-core and voice-core; practical facts are invented and labeled fictional.
- 2026-11-03: Added Half Acre Club's look from Scott's direction ("a seed packet that's spent a week on the kitchen counter"): visual-system.json, art-direction, and spike/build-tokens.ts to generate tokens.css. Contrast check showed pea green (3.9:1) and tomato red (4.1:1) fail small-text contrast on cream, so both are limited to large type and marks and all body copy is soil brown. Fonts (Rubik, Atkinson Hyperlegible, Caveat) are stand-ins marked needs-review.
- 2026-11-03: Added Scott's generated reference photos for the three starting shots to brands/half-acre-club/uploads (split from one triptych, original kept). Scott approved the contrast limits and stand-in fonts. The box photo reads "BOX No. 014", which contradicted the invented 2023 founding date, so positioning-core now says early 2025: a photo is a source, and the fiction has to agree with it.
- 2026-11-03: Completed the Half Acre Club kit draft: brand-about, audience-renters, terminology, voice-examples, social-rules, guardrails, readme and _retrieval-rules. Converted positioning-core from Markdown to YAML to match the spec's format table (YAML chunks keep front matter as the first YAML document). Added positioning-core to the post profiles as load-if-relevant, since the facts list is what stops posts inventing prices and dates. voice-examples and social-rules are medium confidence: only the reference line came from Scott.
- 2026-11-03: Added the messy uploads Scott wrote (about-us.md and rough-notes.pdf) and reconciled the kit against them. Both say pea shoots is the first box, which overturned two things I had derived from the generated photo's "BOX No. 014" label (box number and an early-2025 founding date); two written sources now beat one photo label, and the clash is logged in readme as a known conflict for intake to catch. Containers come from home, not the box. New sourced lines ("One small thing to grow.", "turn the tub"), two banned words ("plant babies", "foolproof"), a long-form register in voice-core, and an "upfront about room and light" differentiator. Lesson: deriving facts from a generated image is weak sourcing.
- 2026-11-03: Started the phase 2 spike with six HTML/CSS post templates (photo-led, type-led, quote card, split, offer badge, event card) and a manifest of named slots with character limits. Templates use only color roles (`--role-background`, `--role-heading`, `--role-accent`...), so visual-system now maps roles to brand colors and `templates/neutral-tokens.css` gives the no-kit baseline a generic white-and-blue look through the same layouts. Fonts are bundled locally (all OFL) so renders don't depend on a font service. `npm run samples` renders every template with lines from voice-examples in both looks, no API needed. First pass: the event and type-led layouts left the bottom half empty, so their copy is now vertically centered.
- 2026-11-03: Built the generation pipeline: prompts/plan.md, write.md and critique.md, and spike/generate.ts running plan → write → render → checks → critique (one revision) with the kit, plus plan → write → render with no kit through the same templates in a neutral look. Two deliberate changes from the CLAUDE.md order: the critique runs after render so Haiku can look at the actual PNG, and cheap code checks (lengths, exclamation marks, banned terms, exact quote, overflow) run before it so the model doesn't have to count characters. The planner sees the photos, not just descriptions, so it can catch the "BOX No. 014" card. Finding: the spec's 3,000-token post_generate budget is too tight for this kit. With source and version bookkeeping stripped, generation context is about 4,300–6,000 tokens per intent (visual-system.json alone is ~800), so the spike loads full profiles and shows the size on the review page rather than dropping chunks. Tested end to end against a mock API; no real posts yet.
- 2026-11-03: First real run (2026-11-03T19-17-52, $0.70). Scott's scores: 1 of 5 with-kit posts client-ready (announcement); kit won 3 of 5 (announcement, tip, testimonial), no kit won promo and event. Gate not passed. What run.json showed: (1) promo: the brief said "lead with the price", so the kit version's headline was "$24 a month. Cancel anytime." and the red stamp was spent on "Box 01"; the baseline led with a benefit and read stronger. (2) Event: the kit version left the optional call to action empty; the baseline's "Bring your questions" won. (3) Tip: Haiku's critique cut "press it with a finger" as an invented fact, though voice-examples uses "Press the soil"; the revision came out flatter. Scott also named the fonts and the plain Rubik wordmark as his main issue. Changes: the promo brief now asks to make the price easy to see rather than lead with it; plan.md says offer terms support the reason to care rather than replace it; write.md gives each slot its own job and fills optional slots when they add a next step; critique.md defines a "fact" narrowly so how-to wording isn't flagged; voice-examples joins the critique profile; quote marks the model wraps around a testimonial are stripped. The review page gets a note field per brief and a "Copy my scores" button.
- 2026-11-03: New type for Half Acre Club. Scott called the Rubik headings and the plain capitals wordmark the weakest part of run 1, so I rendered three directions on the same layouts (seed-packet serif, hardware-store slab stamp, condensed grotesk) and he picked the seed-packet serif: Fraunces with its soft and wonky axes on for headings, the testimonial quote and the price stamp, and a new wordmark, "Half Acre" in Fraunces italic over a small, widely spaced CLUB. Body (Atkinson Hyperlegible) and handwriting (Caveat) stay. visual-system gains `variation` and `lockup_style`, which build-tokens turns into CSS variables, so templates stay brand-agnostic. Rubik is removed.
