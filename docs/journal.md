- 2026-11-03: Phase 3 scaffold. Next.js 16 (App Router) at the repo root for Netlify; the spike's pure code (model config, chunk selection, prompt filling, schemas, the Claude call) moved to `core/` so the app reuses it unchanged, and a build step bundles `prompts/`, `templates/` and the demo kit into a server-only module because Netlify functions don't ship files read from disk. Every guard in the spec's table that lives in code is in, with 17 tests. Three things the platform forced: (1) Netlify ends a function at 60 seconds, so plan and write are separate requests, with the plan kept server-side so the browser can't swap it; (2) Netlify's request limit is about 4.5 MB, below the spec's 5 MB photo cap, so phase 4 should shrink photos in the browser before upload; (3) Netlify's own docs warn against counters on Blobs, so the tripwire reserves each call's worst case (estimated input plus every allowed output token) with compare-and-swap writes, then settles at the real cost. Any race overcounts, and the Console workspace's monthly limit sits behind it. The app runs plan and write but not yet critique, which reads the rendered PNG; it returns once posts render in the browser. `npm run gate` checks the phase 3 gate against the deployed site for free.
- 2026-11-03: **Phase 3 gate passed** on the deployed site (rainbow-souffle-b79aad.netlify.app): `npm run gate` refused raw prompts, model overrides, prompts hidden in the brief, a 501-character message, an 11-page PDF, a 5 MB+ photo and a non-image file, and, after the day's real spend passed a lowered cap, every new session, post and write (503 `daily_cap_reached`). Two things the first deploy taught: (1) every storage read hung for 30 seconds and ended in a 504, because Netlify Blobs was calling through the `fetch` Next.js wraps; Blobs now uses the original fetch with a 4 s per-attempt and 12 s per-operation limit and logs failures. The session cap (4 posts) stopped the test before the spend cap did, so the tripwire was checked by lowering the cap below what had already been spent that day.

- 2026-11-04: Phase 5, step 2: the intake conversation. Scott chose our own small loop over CopilotKit (the spec's earlier pick): CopilotKit brings its own runtime for model calls, and every call here has to go through the spend reservation, the kill switch and the ~26-second function limit, so one endpoint (`/api/intake`) runs each turn as a single guarded Haiku call.
